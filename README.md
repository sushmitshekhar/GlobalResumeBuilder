**An ATS-optimized, international resume builder designed for Indian professionals seeking visa-sponsored jobs abroad.**

Build a polished, professional CV in minutes — with live preview, real-time ATS scoring, and multiple export options. No sign-up required. Your data never leaves your browser.

## ✨ Features

| Feature | Description |
|---------|-------------|
| **3 Professional Templates** | Modern (default), Europass (EU-style), and Minimal (classic serif) |
| **5 Accent Colors** | Navy, Teal, Violet, Crimson, and Slate — instant preview update |
| **Live ATS Score** | Real-time compatibility scoring with 11 criteria and color-coded tips |
| **Structured Entries** | Add, reorder, and delete work experience and education entries |
| **Accordion Form** | Collapsible sections keep the form organized and easy to navigate |
| **Zoom Preview** | Zoom in/out on the live CV preview (50%–150%) |
| **Save & Load Drafts** | Persist your progress in localStorage — resume where you left off |
| **Markdown Export** | Copy a clean Markdown version of your CV to clipboard |
| **Print to PDF** | Native browser print with a clean, print-optimized layout |
| **Visa Eligibility Callout** | Highlight your nationality and visa sponsorship openness |
| **Certifications Section** | List professional certifications (one per line) |
| **Key Projects Section** | Describe standout projects with Markdown formatting support |
| **Responsive Design** | Works on desktop, tablet, and mobile screens |

## 🛠️ Tech Stack

- **HTML5** — Semantic markup with SEO best practices

## 🚀 How to Use

### Option 1: Open Locally
1. Clone or download this repository
2. Open `index.html` in any modern browser
3. Start building your resume!

```bash
# Clone the repo
git clone https://github.com/sushmitshekhar/GlobalResumeBuilder.git

# Open in browser
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

### Option 2: Hosted Version
> **Live Demo:** [https://sushmitshekhar.github.io/GlobalResumeBuilder/](https://sushmitshekhar.github.io/GlobalResumeBuilder/)

---

## 📋 Usage Tips

1. **Fill in your details** in the left panel — sections are collapsible for easy navigation
2. **Watch the live preview** update in real-time on the right
3. **Check your ATS score** — aim for 90%+ for the best results
4. **Switch templates** and accent colors to find your preferred style
5. **Save your draft** to come back to it later
6. **Print to PDF** using `Ctrl/Cmd + P` or the Print button
